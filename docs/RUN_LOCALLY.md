# Run Locally

This is the simplest way to see the site on your machine.

## Prerequisites
- Install Node.js 20 or newer
- Install npm, which usually comes with Node.js

## Steps
1. Open Terminal
2. Go into this project folder
3. Run `npm install`
4. Run `npm run dev`
5. Open `http://localhost:3000`

## What happens
- Next.js starts a local development server on your computer
- The website is not public yet
- You can refresh the browser and see code changes immediately

## Main files to look at first
- `app/page.tsx`
- `app/layout.tsx`
- `components/SiteHeader.tsx`
- `components/SiteFooter.tsx`
- `app/globals.css`
